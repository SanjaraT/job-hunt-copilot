# AI Job Hunt Copilot

A personal tool that scrapes job listings (bdjobs + LinkedIn), scores each
one's relevance against my resume using an LLM, emails a daily digest of
top matches, tracks application status, and drafts tailored cover letters.

Built as a capstone for the FlyRank "10x Solution" track and as a
standalone portfolio project.

Status: Milestone 1 (scaffolding) complete.

See `docs/my_10x_solution.md` for the full problem/solution writeup.
